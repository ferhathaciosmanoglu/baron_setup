BARON OTOMATİK GÜNCELLEME - GITHUB SECRETS

1) GitHub kaynak kod reposunu aç.
2) Settings > Secrets and variables > Actions > New repository secret bölümüne gir.
3) Şu secret'ları oluştur:

TAURI_SIGNING_PRIVATE_KEY
Değer: updater-keys/baron-updater.key dosyasının TAM içeriği

TAURI_SIGNING_PRIVATE_KEY_PASSWORD
Değer: boş parola kullandığımız için boş bırakılamıyorsa tek boşluk yerine yeni anahtar üretirken parola belirle. Bu paket için workflow'da secret tanımlamak yerine değeri boş string olarak da bırakabilirsin.

ÖNEMLİ:
- updater-keys/baron-updater.key dosyasını GitHub'a yükleme.
- Bu özel anahtarı kaybedersen mevcut kullanıcılara yeni güncelleme gönderemezsin.
- updater-keys/baron-updater.key.pub paylaşılabilir; açık anahtar tauri.conf.json içine eklenmiştir.

YENİ SÜRÜM YAYINLAMA:
1) package.json, src-tauri/Cargo.toml ve src-tauri/tauri.conf.json içindeki sürümü aynı yap.
2) Git commit ve push yap.
3) Örnek etiket:
   git tag v1.2.0
   git push origin v1.2.0
4) GitHub Actions otomatik olarak Setup.exe, imza ve latest.json oluşturur.
